Zyneria Connect

A hackathon project built around the theme of automating a person's life toward productivity. This repo currently contains the entry point of that vision — a polished authentication experience—built with React, TypeScript, and Tailwind CSS.

Vision:-

Zyneria aims to help people automate and streamline their daily routines to be more productive — reducing friction around the small decisions and repetitive tasks that eat into focus time.

What's built so far :-

1. Login and sign-up screens with a shared, animated auth overlay
2. Form validation (required fields, inline error messages)
3. Guest login option for quick access without an account
4. Light/dark theme toggle
5. Client-side auth state managed via React Context (AuthContext)

Tech stack:-

1. React + TypeScript
2. Vite for build tooling
3. Tailwind CSS + shadcn/ui components
4. React Router for navigation
5. TanStack Query for data-fetching setup

Notes/Status:-

Given the hackathon's time constraints, this submission focuses on the authentication and onboarding layer — the "front door" of the product. Login and sign-up are currently simulated on the client side (no backend or real credential verification yet). The main dashboard/productivity features beyond login are planned but not yet built.
